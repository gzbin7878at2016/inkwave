# Boss静态道具空间剔除调查（尚未产品化）

当前正式帧率未稳30；此前隐藏props的单段调查没有证明整局提帧，不能直接降低模型质量。本轮先只读真实手机构建的4个最大静态道具桶，验证是否值得进一步实验保守空间剔除和BatchedMesh。

`node tools/investigate-boss-prop-culling.mjs`在独立桌面浏览器加载现有dist-mobile并正常构建Boss，按8米网格对原三角形的质心分组，组包围盒覆盖每个完整三角形的全部顶点。只估算，不截断、简化或替换几何。核对全部三角形仍被计入，统计共享顶点跨组后的重复量及属性类型、逻辑几何字节。

输出真实加载相机及4个明确标为估算视角的可剔除三角比例。额外视角不是自动游玩轨迹；WEBGL_multi_draw支持与候选逻辑字节也不是性能成绩。报告在本机releases/investigation/boss-prop-culling-estimate.json，不提交原始大数组。

只有可剔除率与内存预算值得继续，才做工具级BatchedMesh副本：保持所有三角形/属性/材质/颜色/阴影/遮挡，验证原参考最终像素、保守视锥、渲染开销、fallback及加载预算；再做手机副本。结果不足就不产品化。PC和普通模式不改，不通过降低2倍高清或人数得分。
