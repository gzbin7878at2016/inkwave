## 如何处理与注意点

1. 直接截断后再次normalize会改变早期响度，因此在OfflineAudioContext中用单位脉冲通过原始Convolver，取得真实归一化后的前段响应；末10ms渐出。实战短IR设置normalize=false，避免二次归一化。
2. 再离线卷积一次验证没有额外时移/幅度变化，PCM必须有限、最大误差≤1e-5、原IR能量保留至少98%。不满足、无API/格式不符、2秒超时，均保留原效果，不阻断Boss或实战重试。
3. 两条全部准备完成才安装；setter异常恢复已改部分。缓存按原AudioBuffer身份和归一化/长度区分，换局可复用；取消不安装。48kHz两短IR共384,000字节，约0.366MiB，原IR保留用于恢复，不把它们当释放收益。
4. Boss准备失败/取消及BossMode.dispose按match恢复，旧局不能恢复新局；若外部后来改了配置，不覆盖外部新值。压缩的是低能量尾音，手机混响空间感会略短，听感仍待人工验收；不能称与原音色完全相同。
