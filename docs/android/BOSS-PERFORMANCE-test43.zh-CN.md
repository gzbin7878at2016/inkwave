# Boss性能候选v43：RG16F边缘缓冲

## 原因与范围

原SMAA边缘目标为RGBA16F，每像素8字节；权重算法只读取RG。RG8曾在浏览器通过，却在当前手机真实1556×740输入中出现2670字节差/max102，因此拒绝。v43只把手机真实Boss加载预检与对局的边缘目标改成RG16F，每像素4字节，保留16位浮点采样精度；权重RGBA16F、HDR颜色、全分辨率、三阶段SMAA、合并Output、正确清零、8人/玩法/物理AI与PC路径保持。

准备在加载遮罩内让帧后重分配原RenderTarget存储，目标/Texture/uniform身份不变，真实FBO必须complete且附件16/16/0/0；失败恢复原RGBA16F并记录fallback。旧准备不能清掉新局；取消/异常/退出/普通模式/PC/演示与销毁恢复原格式。resize沿用格式，后续尺寸仍完整，无新增帧内GL查询。统计逻辑存储节省，不能当GPU实测功耗或FPS。

## 提交前验证

- 当前手机Adreno730/WebView131，结算后同一真实HDR输入：1556×740最终输出逐字节差0，146674非空边缘样本全二值，FBO16/16/0/0，权重不变、原目标恢复，原F16目标没有被销毁。USB日志194811-537372-3ed5fedd源码核对f7并关闭。此轮实际战斗仍v42原缓冲，**不是RG16F实战帧率**。
- 边缘格式比较54组HDR高亮/透明/图案/角度/奇数尺寸，最终字节差0、439690非空边缘采样与恢复通过。GL读取使用WebGL允许的RGBA/FLOAT，不用底层驱动公布但验证层拒绝的RG组合。
- 实际候选接口72组DPR/色调/图案/透明度/角度最终字节差0；真实RG16F FBO/附件、目标/Texture/uniform身份、权重精度与4次原绘制、resize/预检/菜单/PC普通演示隔离/取消/重叠准备/异常fallback/真实Renderer/dispose通过。
- 原完整Boss准备、取消/绘制异常恢复、12个小怪资源复用检查通过。语法检查完成后先中文提交推送，再干净构建安装真机。
