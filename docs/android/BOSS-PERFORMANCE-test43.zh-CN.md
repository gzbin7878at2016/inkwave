# Boss性能候选v43：RG16F边缘缓冲

## 原因与范围

原SMAA边缘目标为RGBA16F，每像素8字节；权重算法只读取RG。RG8曾在浏览器通过，却在当前手机真实1556×740输入中出现2670字节差/max102，因此拒绝。v43只把手机真实Boss加载预检与对局的边缘目标改成RG16F，每像素4字节，保留16位浮点采样精度；权重RGBA16F、HDR颜色、全分辨率、三阶段SMAA、合并Output、正确清零、8人/玩法/物理AI与PC路径保持。

准备在加载遮罩内让帧后重分配原RenderTarget存储，目标/Texture/uniform身份不变，真实FBO必须complete且附件16/16/0/0；失败恢复原RGBA16F并记录fallback。旧准备不能清掉新局；取消/异常/退出/普通模式/PC/演示与销毁恢复原格式。resize沿用格式，后续尺寸仍完整，无新增帧内GL查询。统计逻辑存储节省，不能当GPU实测功耗或FPS。
