- 触屏通过 pointerId 固定职责：模拟摇杆径向死区、右侧相对转向、独立开火/跳跃/潜墨/副武器/大招/欢呼、地图数字选点。转向按 CSS 像素累计，不乘 dt 或 DPR。

## 11～14 第二批：掉线出口、传输保护与结算修复

- APK 的 localhost 明确使用现有生产 WSS 中继；保留网页本机调试路由和显式 relay 覆盖。未部署/更改公共中继。
- 进入后台主动离房；网络插件报告离线时离房并提示重新加入。没有实现“原局无缝重连”，不能据此承诺切网不断局。

- 无公网副作用的确定性测试通过：WSS/本机路由、显式覆盖、旧消息、正常退出、心跳超时、队列积压。
