# Boss v45候选：异步小地图像素计算

## 范围与行为

只为手机真实Boss在最终setViewerTeam之后、加载遮罩内准备Worker；PC、普通模式、演示保持原同步入口。原固定2倍高清/SMAA/8人、AI/物理子步、武器与涂地判定不变。Minimap.owner的代码使用只在墨迹像素归属/白色闪光；区域对象z.owner是另一字段，实际涂地/跳跃不读取该像素数组。

保持bilinear/浮雕/颜色/owner/闪光公式和完整分辨率、0.15秒与三段调度。每段复制当时grid快照，最多3个请求；回调只保存结果，原Minimap.update中按序应用Canvas。墨迹因此可能比同步路径晚1～3个地图更新帧；实时人物点仍每帧由原_compose绘制，不等待Worker。

超过3更新帧或250ms、消息错误、数组/视角重建、换色或force时停止本局Worker，丢弃迟到队列并完整走原同步计算；不会在战斗中反复分配大工作集。暂停/后台清理后恢复时原完整首刷，取消准备、旧局释放不能覆盖新局。自然结算释放，统计保存在原地图，真实上传日志render.minimapWorker可读取调用/应用/延迟/原因/回收数。250ms是候选数据失效保护，不放宽游戏30FPS验收。

## 存储与风险

纯算法与传输层移至src/platform，tools重新导出同一实现，避免实验与产品两份代码漂移。Worker持久数组当前手机预计约6.9MB，工作集/在途逻辑预算12MiB、最多50万像素；不代表总进程物理内存。grid输入缓冲随结果传回主线程复用，ink/flash/owner行缓冲主循环复制上传后转移回Worker复用，最多3个回收槽；无帧内布局/GL查询。避免每段新建约0.8MB输出造成持续GC压力。

Worker额外线程仍可能竞争CPU、增加内存或延迟；副本实验的显式Main节省不能代表正式帧率。若真机实际未启用、频繁回退或正式无收益，撤回候选，不以兼容性成功代替稳定30。
