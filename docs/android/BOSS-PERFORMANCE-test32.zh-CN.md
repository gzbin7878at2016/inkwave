# Boss 第32批：缓存小地图未变化像素

## 范围与原因

只作用于手机实际Boss对局，PC、普通对局、菜单和演示沿用原路径。第31批30秒V8采样中，`Minimap._drawInk`自耗时800.7ms，是本批调查依据；这不代表全部瓶颈，也不能由此推算整局提帧幅度。

保留固定2倍高清、SMAA、8人、物理、AI、枪口位置、伤害和音效。小地图分辨率、0.15秒刷新、三段刷新顺序、强制刷新、双线性插值、浮雕、队伍颜色及变色闪光保持原规则。

## 实现与边界

1. Boss加载期间，按像素预分配网格样式和颜色签名缓存，总量上限8MiB，超过上限直接走原入口。分配失败不阻止原小地图工作。
2. 每像素四个网格值不变时复用原透明度计算。当前像素及浮雕邻居的样式、配色未变时复用RGB；透明度、owner和闪光仍逐项处理，避免清除后重涂同色时遗漏。
3. 只有位图内容变化才提交对应Canvas区域。第一次访问每一行仍强制提交，避免初始透明区或先部分刷新遗留旧图。
4. 固定96个采样位置检测大范围变化，超过有效样本的一半变化时直接使用原计算入口，并使旧缓存失效；零散变化使用缓存，局部大量变化跳过RGB签名比较。
5. 地图重建、网格/中间数组替换、离开Boss场景后丢弃缓存。准备取消/失败、真实BossMode.dispose均清理，旧对局清理不得误删新对局缓存。
6. 真机采样结束才读取有界计数器；不向正式每帧采样新增逐像素探针。
