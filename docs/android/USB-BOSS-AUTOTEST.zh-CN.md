# USB自动Boss验证与v1.0.13记录

## 当前结论

2026-10-26，HONOR ALP-AN00 / Android 14 / WebView 131.0.6778.260 / Adreno 730，v13真实自动游玩61.028秒、1700帧：平均27.856FPS，p50=33.4ms、p95=50ms、p99=66.7ms，100ms及以上6帧。固定2倍高清、SMAA、8人Boss；本轮未满足稳定30帧。已执行接近Boss、侧移、连续开火、间歇跳跃、潜墨，并尝试副武器/大招；后两项按正常墨量/充能限制，输入次数不代表成功次数。死亡和复活均沿用正常规则。

随后方法级调查约60.744秒、平均22.867FPS，含额外探针开销且温度/路线不同，不能与前一轮直接计算性能差。HUD方法平均耗时中Boss HUD约1.585ms、墨量条约0.700ms、小地图界面约0.330ms；这是调查优先级，尚非已证实优化收益。系统曾报告热状态2，测试必须同时保留当前HAL温度，不能只取缓存温度。

## 执行命令

1. 解锁并通过USB授权，执行 `./tools/start-usb-debug.ps1`。多设备使用 `-Serial` 指定手机；不可连接时先修复连接，不绕过安全暂停。
2. 安装本次APK并启动游戏，等菜单就绪。脚本只连接正在运行的com.demoink.inkwave，使用本机9223端口转发WebView；执行期间不要并行运行另一个使用9223的工具。
3. PowerShell执行：

```powershell
$env:ANDROID_SERIAL='A38YUT3C19022796'
$env:BOSS_TEST_SECONDS='60'
$env:BOSS_TEST_NAME='v13-baseline'
$env:BOSS_METHOD_PROBE='0'
node tools/check-phone-boss-performance.mjs
```

4. 原始帧间隔、每2秒角色坐标/存活/墨量/输入意图/8人数量、CPU分段、最终诊断及前后温度，保存到 `releases/investigation/phone-boss-v13-baseline.json`。每次使用新名称避免覆盖；这些本地原始日志不提交Git。
5. 脚本自动开始60秒Boss对局；每帧通过原输入控制器模拟操作，不修改血量、伤害、人数、模拟速度或角色位置。默认短轮等待本局自然结束；仅显式指定超过60秒的长期测试才在自然结算后重开。加载/开场/结算不计入帧耗统计，但战斗内全部慢帧保留。
6. 需要调查HUD时将BOSS_METHOD_PROBE设为1并使用独立名称，结果明确标记带探针；完成后设回0做最终验收。方法级调查不能作为最终性能成绩。
7. 长期验收将BOSS_TEST_SECONDS设为1800。脚本的stable30Validated要求：无探针、至少1800秒实际战斗、平均至少29.5FPS、p95不超过36ms、p99不超过50ms、100ms以上帧为0；同时固定2倍、SMAA、8人Boss、无shader失败/安全暂停。该标记只涵盖本机本场景，不代表所有手机/地图均通过。
8. status=measured仅表示完整采样结束，不能等同稳定30帧；aborted表示中断/图形异常/时长不足，禁止当作通过。每2秒保存已采数据，USB断线立即拒绝请求并保存失败信息，正常收尾恢复原游戏方法和输入。若直接杀死Node而未收尾，必须重启游戏，避免遗留包装器重复统计。

## 已知中断与风险

- 首次Boss采样USB失联，用户重新插线授权后恢复；端口映射丢失可解释“USB接收未就绪”，尚不能解释物理链路为何断开。
- 早期重复采样在未重启应用时叠加了记录包装器，帧数重复；phone-boss-reconnected-baseline数据无效，不可引用其平均帧率。本工具已加入恢复机制及匹配对局对象，正式复测前重启过应用。
- 一次v12强制退出后的冷启动出现多个“shader编译成功但链接失败、驱动错误日志为空”，安全保护停止渲染。原始记录为phone-restart-gpu-failure.json，原因未确定；安装启动v13后此轮未复现，不能据此宣称根因已修复。

## 每轮自动上传与关闭

按用户要求，完成一局后先结束采样、恢复输入，再点击真实上传按钮，要求USB成功回执并核对releases/logs中新文件的源码提交，最后adb force-stop仅关闭游戏，并检查进程消失。电脑端完整采样文件仍单独保存。上传失败时记录upload.ok=false，保留已采数据后关闭，不能声称已上传；断线时可能无法关闭，记录appClosed=false等待重连。启动图形失败等中断也尝试保存/上传日志后关闭。
